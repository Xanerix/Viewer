# Viewer

一个 Windows 原生的轻量图片查看器。

## 手势

### 鼠标

| 输入 | 行为 | 备注 |
|---|---|---|
| 左键按住 | 切到原始比例，拖动平移 | 松开回到适应窗口 |
| `Alt` + 左键拖 | 移动窗口 | 支持贴靠 |
| 中键单击 | 切换全屏 | |
| 中键按住 | 锁定原始比例 | 按住期间隐藏光标，松开时还原光标位置 |
| 右键 | 退出 | 单独按下才生效 |
| 滚轮 ↑ / ↓ | 上一张 / 下一张 | 左键按住期间忽略 |
| 右键 + 滚轮 ↑ / ↓ | 逆时针 / 顺时针 90° | |
| 拖拽窗口边缘 | 调整窗口尺寸 | 全屏时禁用 |

### 键盘

全部在松开按键时触发，按住不会连续翻页。

| 按键 | 行为 |
|---|---|
| ↑ / ↓ | 上一张 / 下一张 |
| ← / → | 逆时针 / 顺时针 90° |
| H / V | 水平 / 垂直翻转 |
| Space | 切换全屏 |
| Delete | 删至回收站 |
| Shift + Delete | 永久删除（会弹确认框） |
| Ctrl + C | 复制图像到剪贴板 |
| Enter | 当前图片缺解码扩展时，前往商店安装 |
| Esc | 退出 |

左键按住时，除 Ctrl 组合与 Esc 外的按键都会被忽略。

## 配置

在 `viewer.exe` 同目录放一个 `viewer.toml`，不放就全用默认值。两项都可省：

```toml
background  = "#101010"           # 只接受 #RRGGBB
window_size = [1280, 720]         # 不超过屏幕分辨率；省略则取当前显示器的一半宽高
```

- 不带参数启动 `viewer.exe`（开始菜单快捷方式即是）会打开设置对话框，确定后整个重写 `viewer.toml`，原有注释不保留。为所有用户安装在 Program Files 时会先弹 UAC 提权。
- 窗口总是在光标所在的显示器上居中。
- 语法错误会在启动时弹框报出行号，然后按默认值启动；单个字段写错只有那一项回落默认值。
